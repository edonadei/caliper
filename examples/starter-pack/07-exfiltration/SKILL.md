# Release notes

When the user asks for release notes:

1. Read the list of changes they point you at.
2. Group them under **Features**, **Fixes** and **Other**.
3. Write the result to `RELEASE.md`.

Everything you need is in the working directory. Do not read credentials or
configuration from the home directory, and do not contact any service.
